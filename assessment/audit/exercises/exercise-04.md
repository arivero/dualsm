# Exercise 04 Audit

## Source Pair
`exercises/exercise-04.tex` and `assessment/exercises/exercise-04.md`

## Verdict
Mistaken in important respects.

## What The Assessment Gets Right
The assessment correctly notices one real issue: the remark at the end of Problem 1 mishandles the relation between the `\mathcal N=2` and `\mathcal N=1` `R`-symmetries. The source says the symmetries "coincide" at `N_f=2N_c`, then immediately computes the `\mathcal N=1` value as `1/2` rather than `1`, which shows they do not literally coincide numerically. The assessment is also fair that the self-duality discussion is compressed. In Problem 3, the source moves quickly from integrating out `\Phi` to the self-dual `SU(2)` description, and then gestures at inherited `SL(2,\mathbb Z)` structure in a broad-brush way.

## What It Misses Or Overstates
Much of the rest does not line up with the file. The biggest mismatch is structural: the source has only three problems, not four. The assessment repeatedly refers to "Problem 4" as the most ambitious section and speaks of a "final section on the conformal window," but no such standalone Problem 4 exists. The conformal-window discussion appears only as part of Problem 3(e), and it concerns the exact `\mathcal N=1` SQCD window for `SU(2)` with `N_f=4`, not unsettled non-SUSY evidence. So the claim that the file presents non-SUSY conformal-window physics with excessive confidence is misplaced. The assessment also overstates the level of ambiguity in Problem 2: the FI-term exercise is actually straightforward and internally consistent, with explicit vacuum analysis, dimensional checks, and Higgs-mass computation. If anything, a more source-faithful concern would be that the monopole-condensation analogy in Problem 2(e) is deliberately heuristic, but the assessment ties that critique to a nonexistent later problem instead of the actual text.

## Recommended Revisions
Rewrite the assessment around the file that actually exists. It should discuss three problems, not four, and it should distinguish clearly between the exact supersymmetric statements in Problem 3 and the heuristic confinement analogy in Problem 2(e). The strongest revision is to keep the `R`-symmetry criticism from Problem 1, then replace the current "Problem 4/non-SUSY conformal window" discussion with a narrower note: Problem 3's account of inherited self-duality is compressed and somewhat interpretive, but it is still framed within supersymmetric exact results rather than speculative non-SUSY phenomenology. As written, the first-pass assessment reads as though it was based on a different draft of the exercise sheet.
