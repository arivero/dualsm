# Content Assessments

[November review of the revised papers](2026-11-20/README.md)

This folder contains one separate content review for each LaTeX source in:

- `lectures/`
- `exercises/`
- `papers/*/paper.tex`

The reviews are organized by source category:

- `assessment/lectures/`
- `assessment/exercises/`
- `assessment/papers/`

These notes focus on content rather than LaTeX mechanics:

- conceptual clarity
- pedagogical flow
- internal consistency
- scope discipline
- strength of argument
- unsupported leaps and concrete revision priorities

The folder name is `assessment/`.

Additional review layers:

- `assessment/audit/` contains source-vs-assessment audits
- `assessment/adjudication/` contains `KEEP` / `REVISE` / `REPLACE` rulings
- `assessment/reassessment/` contains fresh `xhigh` rewrites for negative adjudication cases

Top-level summaries:

- `assessment/FINAL-SCORECARD.md`
- `assessment/GENERAL-REPORT.md`
